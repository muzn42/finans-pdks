Antigravity / Android Studio Kurulumu:
1. İndirdiğiniz finans_pdks_app.zip dosyasını istediğiniz bir dizine çıkartın.
2. Android Studio veya Antigravity içerisinden "Open" diyerek klasörü seçin.
3. Gradle senkronizasyonu tamamlandıktan sonra doğrudan Run veya Build alabilirsiniz.
